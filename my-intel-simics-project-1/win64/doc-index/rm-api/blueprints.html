blueprints.expand

Synopsis

blueprints.expand(
    *args,
    params=None,
    logger=<RootLogger root (WARNING)>,
    **kwd
) -> blueprints.impl.BlueprintBuilder

Description

Expand a blueprint and return the resulting Builder object, for inspection or instantiation. Either a single blueprint function is given, which is then expanded at the empty namespace (i.e. the object hierarchy root), or a top namespace name and blueprint function is given.

Blueprint parameters can be provided using the ‘params’ argument, as a (nested) dict, name -> value.

class blueprints.Builder

Synopsis

class blueprints.Builder(builder: 'BlueprintBuilder')

Description

Interface used by blueprint functions to add objects and handle state.

A Builder instance is passed as the first argument to a blueprint function. Its methods are primarily used to add objects and sub-blueprints and to handle state.

Synopsis

blueprints.Builder.establish_binding(
    type: type[~BindingT],
    src: blueprints.types.Namespace,
    dst: blueprints.types.Namespace
) -> ~StateT

Description

Reads the Binding of type ‘type’, which must have been exposed at node ‘src’ and re-exposes it at node `dst“.

Note that a Binding is a 1-1 channel and hence can only be read once.

Description

If ‘state’ is a state instance, then that instance is bound to the specified node. Note that a specific state instance can be bound to multiple nodes.

blueprints.Builder.read_state

Synopsis

blueprints.Builder.read_state(
    name: blueprints.types.Namespace,
    state: type[~StateT],
    *,
    private=False,
    allow_local=False
) -> ~StateT

Description

Returns a state instance of type ‘state’ obtained from the node ‘ns’. If the node ‘ns’ does not provide the state, then the state is obtained from the first hierarchical ancestor which provides it.

If no ancestor provides the state, or if ‘private’ is set to True, then a local state instance is created and returned instead. The same state instance will always be returned for a specific value of ‘ns’. A local state is not accepted if ‘allow_local’ is set to True.

State instances are bound to a specific node with the ‘expose_state’ method.

class blueprints.Priority

Synopsis

class blueprints.Priority(
    value,
    names=None,
    *,
    module=None,
    qualname=None,
    type=None,
    start=1
)

Description

Priority of a value written to a state field.

When multiple blueprints write to the same field, the value with the highest priority is used. Writing different values with the same priority is an error. Values are written with NORMAL priority unless wrapped using Default() or Override().

class blueprints.Param

Synopsis

class blueprints.Param(
    name: str,
    desc: str,
    config: type[blueprints.types.Config],
    ptype=None,
    default=None,
    member_name=None,
    allow_empty=True,
    advanced=0,
    telemetry=False
)

Description

Blueprint parameter definition.

Each parameter is tied to a data member of a Config class, from which its default value and type are obtained.

  • name: user-facing parameter name, and the name of the Config member unless member_name is given.
  • desc: user-facing description.
  • config: the Config class the parameter is bound to.
  • ptype: parameter type. Required if the default value is None, otherwise obtained from the Config member.
  • default: default value, overriding the Config member default.
  • member_name: name of the Config member, if different from name.
  • allow_empty: whether an empty value is accepted.
  • advanced: advanced level used by the target parameter framework.
  • telemetry: whether the parameter is included in telemetry.

class blueprints.ParamGroup

Synopsis

class blueprints.ParamGroup(*args, **kwargs)

Description

Blueprint parameter group declaration.

Imports the parameters of another blueprint as a sub-tree.

  • name: name of the sub-tree. The importing blueprint must expand import_bp at a namespace matching this name (or the value of the ns parameter, if set).
  • desc: user-facing description.
  • import_bp: name of the blueprint whose parameters are imported.
  • ns: name of a parameter whose value gives the namespace where import_bp is expanded, if different from name.
  • count: name of an integer parameter giving the number of copies of the imported blueprint, for dynamic parameters.
  • enable: name of a boolean parameter controlling whether the imported blueprint is added at all, for dynamic parameters.

ParamGroup(name, members) with a list of parameter definitions can also be used to group parameters explicitly.
