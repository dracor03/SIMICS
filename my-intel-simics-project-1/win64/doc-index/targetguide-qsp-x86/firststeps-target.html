qsp-x86/firststeps

  • machine
    • system:name
      Name of the machine. Used for the top-level component.
      • Type: str
      • Default value: board
    • system:info
      A short string describing what this system is.
      • Type: str
      • Default value: Simics QPS X86 Firststeps
    • hardware:system:name
      Name of the machine. Used for the top-level component.
      • Type: str
      • Default value: ^machine:system:name
      • Required: True
    • hardware:memory_megs
      Amount of RAM in the machine, in MiB. The highest supported value is 65536 (64 GiB).
      • Type: int
      • Default value: 8192
    • hardware:processor:class
      It should be specified as processor component class without the “processor_” prefix and with underscores replaced with hyphens, e.g. x86-skylake. Tip: to obtain the list of processor component classes please use the “list-classes substr = processor_” Simics command.
      • Type: str
      • Default value: x86QSP3
    • hardware:processor:num_cores
      Number of cores per physical processor or slot in the machine. Allowed values are 1 - 128.
      • Type: int
      • Default value: 1
    • hardware:processor:freq_mhz
      Processor frequency in MHz.
      • Type: int
      • Default value: 2000
    • hardware:processor:cpi
      Clock cycles per executed instruction for the processors. Must be a power of 2.
      • Type: int
      • Default value: 1
    • hardware:processor:num_slots
      Number of physical processors in the machine.
      • Type: int
      • Default value: 1
    • hardware:processor:num_cores_small
      Number of small cores per physical processor in the machine (only applicable if the processor class specified by the cpu_comp_class parameter supports heterogeneous setups).
      • Type: int
      • Default value: 0
    • hardware:processor:num_threads
      Number of threads per processor core in the machine.
      • Type: int
      • Default value: 1
      • Allowed values: [1, 2, 4]
    • hardware:processor:num_threads_small
      Number of threads per small core in the machine (only applicable if the processor class specified by the cpu_comp_class parameter supports heterogeneous setups).
      • Type: int
      • Default value: 0
      • Allowed values: [0, 1, 2, 4]
    • hardware:processor:apic_freq_mhz
      APIC frequency in MHz.
      • Type: int
      • Default value: 133
    • hardware:consoles:con0:create
      Create a console for COM1 (a.k.a. com[0]).
      • Type: bool
      • Default value: True
    • hardware:consoles:con0:show
      Automatically display the text console on the first serial port.
      • Type: bool
      • Default value: True
    • hardware:consoles:con0:fg_color
      The foreground color, or RGB in #12ab89 format.
      • Type: str
      • Default value: white
    • hardware:consoles:con0:bg_color
      The background color, or RGB in #12ab89 format.
      • Type: str
      • Default value: black
    • hardware:consoles:con0:width
      • Type: int
      • Default value: 80
    • hardware:consoles:con0:height
      • Type: int
      • Default value: 30
    • hardware:consoles:gfx_con:create
      Create a graphics console.
      • Type: bool
      • Default value: True
    • hardware:consoles:gfx_con:show
      Automatically display the graphics console.
      • Type: bool
      • Default value: True
    • hardware:storage:disk0:name
      The name of the disk component.
      • Type: str
    • hardware:storage:disk0:slot
      IDE/SATA/PCIe slot to connect to.
      • Type: str
    • hardware:storage:disk0:create
      • Type: bool
      • Default value: True
    • hardware:storage:disk0:interface
      Create and connect to the target machine a virtual hard disk of type SATA, IDE, or NVMe. Simics object machine_name.disk0 is created and connected to the target machine.
      • Type: str
      • Default value: sata
      • Allowed values: [‘sata’, ‘ide’, ‘nvme’]
    • hardware:storage:disk0:image
      Disk image file for the machine_name.disk0 virtual disk. Files in craff (Simics own file format), VHDX, and raw formats are supported.
      • Type: file
      • Default value: ^machine:software:linux:empty_image
    • hardware:storage:disk0:size
      Size of the machine_name.disk0 virtual disk in bytes. If NIL, the size of disk0_image is used.
      • Type: int
    • hardware:storage:disk1:name
      The name of the disk component.
      • Type: str
    • hardware:storage:disk1:slot
      IDE/SATA/PCIe slot to connect to.
      • Type: str
    • hardware:storage:disk1:create
      • Type: bool
      • Default value: True
    • hardware:storage:disk1:interface
      Create and connect to the target machine a virtual hard disk of type SATA, IDE, or NVMe. Simics object machine_name.disk0 is created and connected to the target machine.
      • Type: str
      • Default value: sata
      • Allowed values: [‘sata’, ‘ide’, ‘nvme’]
    • hardware:storage:disk1:image
      Disk image file for the machine_name.disk0 virtual disk. Files in craff (Simics own file format), VHDX, and raw formats are supported.
      • Type: file
      • Default value: ^machine:software:linux:auxiliary_image
    • hardware:storage:disk1:size
      Size of the machine_name.disk0 virtual disk in bytes. If NIL, the size of disk0_image is used.
      • Type: int
    • hardware:storage:usb_disk:device:name
      The name of the USB disk component.
      • Type: str
    • hardware:storage:usb_disk:device:create
      Set to true if a USB disk should be created.
      • Type: bool
      • Default value: True
    • hardware:storage:usb_disk:device:slot
      USB connector slot to connect to.
      • Type: str
    • hardware:storage:usb_disk:device:image
      The image to use for the USB disk.
      • Type: file
      • Default value: ^storage:usb_disk:image
      • Required: True
    • hardware:storage:usb_disk:image
      The image to use as USB disk to boot from.
      • Type: file
      • Default value: ^machine:software:linux:os_image
      • Required: True
    • hardware:rtc:time
      The date and time of the simulated real-time clock set when the configuration is created. The format is “YYYY-MM-DD HH:MM:SS”. Can also be set to “auto” to use the current host time.
      • Type: str
      • Default value: auto
    • hardware:usb_tablet:create
      Connects a USB tablet device for input using absolute positioning that provides a better user experience than a mouse.
      • Type: bool
      • Default value: False
    • hardware:apic_bus:class
      APIC bus class. It should be the apic bus class that comes with the same module as the apic used in the CPU model. If set to “auto_apic_bus” the script will attempt to find the correct apic bus class automatically. If that fails the apic-bus class will be used.
      • Type: str
      • Default value: auto_apic_bus
    • hardware:nic:mac_address
      MAC address of the built-in Ethernet adapter in the ICH10 chipset. The format is “XX:XX:XX:XX:XX:XX”. Can also be set to “auto” to obtain an auto-generated unique MAC address.
      • Type: str
      • Default value: auto
    • hardware:firmware:bios
      BIOS file.
      • Type: file
      • Default value: ^machine:software:firmware:uefi:image
      • Required: True
    • hardware:firmware:lan_bios
      ROM BIOS file for the ICH10 LAN Ethernet adaptor
      • Type: file
      • Default value: ^machine:software:firmware:lan_bios
    • hardware:firmware:spi_flash
      The ICH10 SPI flash file to use.
      • Type: file
      • Default value: ^machine:software:firmware:spi_flash
      • Required: True
    • hardware:simulation:enable_break_on_reboot
      Interrupts the simulation if the machine is rebooted.
      • Type: bool
      • Default value: False
    • hardware:simulation:system_clock:enable

      • Type: bool

      • Type: str

      • Type: bool
      • Default value: False
    • hardware:simulation:use_vmp
      Enables host virtualization (VMP) for better simulation performance. This option affects simulated time. See the performance chapter in the Simics User’s Guide for more information about VMP.
      • Type: bool
      • Default value: True
    • hardware:simulation:silence_logs
      When set to true, silence logs and warnings for problems that do not cause simulation problems.
      • Type: bool
      • Default value: True

      • Type: int
      • Default value: 0
    • network:switch:ethernet_switch:goal_latency
      Goal latency in seconds for communication (see also the set-min-latency command)
      • Type: float
      • Default value: 1e-05
