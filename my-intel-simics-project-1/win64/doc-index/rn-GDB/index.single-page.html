Simics GDB (Package Number 1031) Release Notes

This document contains release notes for the package Simics GDB (package number 1031) for Simics 7. The release notes describe new features, bug fixes, and other changes.

Changes Since Version 7.0.0

The following is a list of changes since the initial 7.0.0 release.

7.14.0 (build 7214)

GDB

  • The OpenSSL library used by GDB has been upgraded to version 3.6.5.

7.13.0 (build 7203)

GDB

  • The OpenSSL library used by GDB has been upgraded to version 3.6.4.
  • The libexpat library used by GDB has been upgraded to version 2.8.4.

7.12.0 (build 7188)

GDB

  • The libexpat library used by GDB has been upgraded to version 2.8.2.
  • The libexpat library used by GDB has been upgraded to version 2.8.1.

7.11.0 (build 7155)

Common

  • The signing certificate on Simics packages has been updated.

GDB

  • The libexpat library used by GDB has been upgraded to version 2.7.5.
  • The libexpat library used by GDB has been upgraded to version 2.7.4.

7.10.0 (build 7125)

GDB

  • The libexpat library used by GDB has been upgraded to version 2.7.3.

7.9.0 (build 7111)

GDB

  • On Linux, fixed a problem running GDB with a host Python version higher than 3.10.

7.8.0 (build 7104)

GDB

  • On Linux, fixed a problem running GDB with a host Python version higher than 3.10.

7.7.0 (build 7080)

GDB

  • The libexpat library used by GDB has been upgraded to version 2.7.1.

7.6.0 (build 7075)

7.5.0 (build 7071)

GDB

  • Fixed a problem starting GDB on Windows.

7.4.0 (build 7050)

GDB

  • The GDB version has been updated to 14.1.

7.3.0 (build 7029)

7.2.0 (build 7023)

Common

  • The signing certificate on Simics packages has been updated.

7.1.0 (build 7007)

Common

  • Updated the batch (.bat) files in the bin folder so that they do not leak environment variables to the current cmd.exe command shell on Windows (fixes SIMICS-21906).

7.0.0 (build 7006)

Common

  • Simics, when launched on Linux, no longer sources the file $HOME/.simics-5.sh (fixes SIMICS-21148)
