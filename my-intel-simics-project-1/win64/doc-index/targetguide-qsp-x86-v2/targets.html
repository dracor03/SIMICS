3 Targets

The QSP-x86-v2 comes with multiple target scripts. Invoking ./simics -l in a Simics project on Linux or simics.bat -l on a Windows host will show the targets available.

  • qsp-x86-v2/hdd-boot
  • qsp-x86-v2/user-provided-linux
  • qsp-x86-v2/yocto-linux
