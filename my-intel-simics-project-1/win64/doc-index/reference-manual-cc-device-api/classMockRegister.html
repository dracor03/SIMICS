void MockRegister::parse_field ( const simics::field_t &  f)
inlineoverridevirtual

Parse the field information.

Add the field or field array into the resource map. The field reuses the memory allocated for the enclosing register. offset 0 is always the least significant bit regardless of bit order e.g. 2 bytes value 0b10100111 | | offset:7 offset:0 => width = 8

Implements simics::RegisterInterface.

◆ set_byte_pointers()

void MockRegister::set_byte_pointers ( const simics::register_memory_t &  byte_pointers)
inlineoverridevirtual

Set the byte pointers for the register's storage.

This function assigns the underlying byte storage locations for the register. It must be called before init() to properly set up the register's memory, ensuring that subsequent initialization and value access operate on the correct storage.

Parameters
byte_pointersA vector of pointers to the bytes that back this register.

Implements simics::RegisterInterface.
