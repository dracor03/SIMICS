Detailed Description

template<log_type_t Type = Sim_Log_Info, int Level = 1, uint64_t Groups = 0>
class simics::LogStream< Type, Level, Groups >

An std::ostream subclass that routes written text to the Simics log API.

Text written to a LogStream is buffered and emitted as a single Simics log message when the stream is flushed (via flush() or std::flush) or when the stream object is destroyed. Trailing whitespace and newlines are automatically stripped before the message is emitted. Nothing is logged if the stream is empty at destruction time.

The three template parameters map directly to SIM_log_message arguments:

Template Parameters
TypeLog type (e.g. Sim_Log_Info, Sim_Log_Error). Defaults to Sim_Log_Info.
LevelLog verbosity level. Only shown when the object's log level is at least this value. Defaults to 1.
GroupsBitmask of log groups. Use 0 to bypass group filtering. Defaults to 0.

Use LogStream when you prefer C++ stream syntax over printf-style format strings, or when you need to redirect an existing std::ostream (e.g. std::cout) to the Simics log system via rdbuf().
