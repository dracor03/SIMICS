<qsp-v2-namespace>.list-bios-build-shas

Synopsis

<qsp-v2-namespace>.list-bios-build-shas

Description

List the SHAs of the repos used to build the BIOS image. The command scans the QSP's ROM content for the build information as it is produced by the BIOS build process. If you use an older or custom BIOS image that does not contain the build information, the command will not be able to find the information.
