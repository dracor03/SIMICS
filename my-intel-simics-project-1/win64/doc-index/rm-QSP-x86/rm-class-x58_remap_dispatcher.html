x58_remap_dispatcher

Description

Translate dispatcher unit. - legacy variant, using old PCIe libraries

Interfaces Implemented

conf_object, log_object, pci_upstream

Connects

default_remapping_unit (optional)
Required interfaces: pci_upstream
gfx_remapping_unit (optional)
Required interfaces: pci_upstream
pci_bus (optional)
Required interfaces: pci_downstream

Notifiers

cell-change
Notifier that is triggered after the object's cell was changed.
object-delete
Notifier that is triggered just before Simics object is deleted.
queue-change
Notifier that is triggered after the object's clock was changed. New clock can be obtained with the SIM_object_clock function.

Attributes

default_remapping_unit
Optional attribute; read/write access; type: o|[os]|n
The default dma remapping unit.

Required interfaces: pci_upstream.

gfx_objs
Optional attribute; read/write access; type: [o*]
List of configuration objects from which transactions will be remapped using the GFX remap unit.
gfx_remapping_unit
Optional attribute; read/write access; type: o|[os]|n
The dma remapping unit used for gfx.

Required interfaces: pci_upstream.
