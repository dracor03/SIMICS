cf9_handler

Description

Device to handle reset and init requests sent from SW to port CF9.

Interfaces Implemented

conf_object, log_object

Connects

init_signal (optional)
Required interfaces: signal
reset_signal (required)
Required interfaces: signal

Notifiers

cell-change
Notifier that is triggered after the object's cell was changed.
object-delete
Notifier that is triggered just before Simics object is deleted.
queue-change
Notifier that is triggered after the object's clock was changed. New clock can be obtained with the SIM_object_clock function.
state-change
Notifier on potential DML state change

Port Objects

bank.regs
cf9_handler.regs
port.system_reset
cf9_handler.system_reset

Commands for this class

  • info – print information about the object
  • status – print status of the object

Attributes

init_signal
Optional attribute; read/write access; type: o|[os]|n
The target to send init signals to. For example, a signal bus.

Required interface: signal

reset_signal
Required attribute; read/write access; type: o|[os]
The target to send resets to. For example, a signal bus.

Required interface: signal

Provided By

generic-pc-support
