irq_pin_to_ioapic

Description

This device redirects incoming signals (maximum 32) to ioapic vectors.

Interfaces Implemented

conf_object, log_object, pci_interrupt

Connects

to_ioapic (required)
Required interfaces: ioapic

Notifiers

cell-change
Notifier that is triggered after the object's cell was changed.
object-delete
Notifier that is triggered just before Simics object is deleted.
queue-change
Notifier that is triggered after the object's clock was changed. New clock can be obtained with the SIM_object_clock function.
state-change
Notifier on potential DML state change

Port Objects

irq_pin_to_ioapic.incoming_signals
port.incoming_simple_irq
irq_pin_to_ioapic.incoming_simple_irq

Commands for this class

  • info – print information about the object
  • status – print status of the object

Attributes

irq_to_ioapic_pin
Optional attribute; read/write access; type: [i{32}]
Map incoming simple irq to outgoing ioapic pin
to_ioapic
Required attribute; read/write access; type: o|[os]
Connect to iopaic

Required interface: ioapic
