<cycle>.bp-trace-time

Synopsis

<cycle>.bp-trace-time (seconds|count) [unit] [-absolute]

Description

Enable tracing for when the processor reaches the point in time that is the amount of time given by count and unit ahead of the time when the command is issued. If -absolute is specified, the time that is traced is instead the specified time from the start of the simulation.

The default time unit is seconds (s), but can be specified as one of: s (seconds), ms (milli-seconds), us (micro-seconds), ns (nano-seconds), ps (pico-seconds), m (minutes), or h (hours).

The seconds argument is retained for compatibility as an alternative for count and is interpreted the same way with regards to the value of unit.

If no processor is specified, the currently selected frontend processor is used.
