<benchmark_db>.add-run-annotation

Synopsis

<benchmark_db>.add-run-annotation run-id "annotation"

Description

Add a user annotation to a specific run. This serves as a comment for the run and is displayed in the output of <benchmark_db>.list-runs. The run-id argument specifies the unique run number to annotate. The annotation argument is a string containing the comment to associate with the run. Multiple annotations can be added to the same run; they will be separated by new lines.
