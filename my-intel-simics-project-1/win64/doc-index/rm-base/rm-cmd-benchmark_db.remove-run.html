<benchmark_db>.remove-run

Synopsis

<benchmark_db>.remove-run run-id

Description

Removes a benchmark-run from the database. The run-id specifies which run to remove.

If removed run removed was associated with a session, the session score will be recalculated. This could cause an incomplete session scores if the run was part of any suites.
