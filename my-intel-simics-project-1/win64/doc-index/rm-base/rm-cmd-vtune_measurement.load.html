<vtune_measurement>.load

Synopsis

<vtune_measurement>.load result-dir

Description

Load an already-collected VTune result directory without running a new measurement. After loading, all report commands (.profile, .save-folded-stacks, .flamegraph, etc.) work exactly as they do after a normal .stop.

The result-dir argument must point to an existing VTune result directory (the vtune_* folder created by a previous .start/.stop pair).

Provided By

vtune-measurement
