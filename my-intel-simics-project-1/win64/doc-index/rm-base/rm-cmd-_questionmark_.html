Synopsis

?text

Description

Send text to the GitHub Copilot AI agent. The agent can execute Simics commands by including <simics-command>command</simics-command> in its response. The command output is fed back to the agent for further analysis. This is the command invoked for each line of input when in AI mode (entered with the ai-mode command).
