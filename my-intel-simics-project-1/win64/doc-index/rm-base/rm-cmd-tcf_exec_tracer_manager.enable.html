<tcf_exec_tracer_manager>.enable

Synopsis

<tcf_exec_tracer_manager>.enable (object|-all)

Description

Enable tracing. Select tracers to enable by using object to select tracer by object name, or -all to select all tracers.

Provided By

tcf-agent
