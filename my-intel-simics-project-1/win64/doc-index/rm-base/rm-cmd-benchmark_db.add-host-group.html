<benchmark_db>.add-host-group

Synopsis

<benchmark_db>.add-host-group "host-group-name"

Description

Add a new host-group-name to the database. Real hostnames, used for benchmarking, can then be added to a this host group, allowing runs on multiple hosts to be seen as the same type of host.

Provided By

benchmark-database
