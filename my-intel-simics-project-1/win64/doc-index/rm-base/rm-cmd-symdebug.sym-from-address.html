<symdebug>.sym-from-address

Synopsis

<symdebug>.sym-from-address address

Description

Returns the name of the symbol that overlaps the specified address in memory. The returned name can be used with other symbol inspection commands such as sym-address, sym-type, and sym-value. This is more general than sym-function; it looks for both function and global variable symbols.

Provided By

tcf-agent
