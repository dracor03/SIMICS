2.5 setup-venv

SYNOPSIS

setup-venv --project project --python python --base simics-base [options]

DESCRIPTION

Creates or updates a Python virtual environment for a Simics project and installs the Simics Python package and any requirements files found in the project or its add-on packages.

OPTIONS

--project
Path to the Simics project.
--python
Path to the Python executable used to create the virtual environment.
--base
Path to Simics-Base.
--venv
Path to the Python virtual environment. If omitted, .venv in the project directory is used.
--with-gui
Include Simics legacy GUI requirements.
--with-dev
Include Simics developer dependencies.
--dry-run
Show the operations without creating or updating the virtual environment.
--verbose
Print more information about the actions taken by the script.
