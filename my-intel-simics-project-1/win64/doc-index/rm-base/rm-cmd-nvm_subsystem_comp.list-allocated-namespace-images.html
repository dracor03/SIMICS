<nvm_subsystem_comp>.list-allocated-namespace-images

Synopsis

<nvm_subsystem_comp>.list-allocated-namespace-images

Description

List all allocated namespace images for the NVMe drive. This includes both active and inactive namespaces. This command is useful for determining which namespace IDs are in use, and their properties, including which controllers the namespace is currently attached to, its UUID, size and backing image.
