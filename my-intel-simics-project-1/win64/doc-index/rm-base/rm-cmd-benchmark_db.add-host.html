<benchmark_db>.add-host

Synopsis

<benchmark_db>.add-host "host-name" operating-system

Description

Add a host-name to the database. This is mostly for testing purposes, since an imported run of a new benchmark, will automatically add execution on new host to the database itself. The operating-system argument should be either Linux or Windows.
