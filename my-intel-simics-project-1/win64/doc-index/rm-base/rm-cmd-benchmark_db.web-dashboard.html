<benchmark_db>.web-dashboard

Synopsis

<benchmark_db>.web-dashboard [port] [-open-browser] [-verbose] [max-report-input-mib] [max-report-json-mib]

Description

Start a local web server that serves an interactive dashboard for exploring benchmark results.

The dashboard provides suite score trends, S-curves, session comparisons, metric-over-time charts, and a data explorer with database schema visualization.

port specifies the TCP port (default 8080).

Use -open-browser to automatically open a browser.

Use -verbose to print the subprocess command line, show server stdout, and enable SQL query logging.

max-report-input-mib limits each compressed report file upload (default 32 MiB). max-report-json-mib limits each report after decompression (default 128 MiB).
