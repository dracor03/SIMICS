<simics-uefi>.add-acpi-table-file

Synopsis

<simics-uefi>.add-acpi-table-file binary-table-file

Description

add-acpi-table adds a binary ACPI table to the list of ACPI tables that will be installed/overridden during boot. The command will try to find an available slot. If it cannot it will raise an error. The required argument binary-table-file is expected to be an AML file.
