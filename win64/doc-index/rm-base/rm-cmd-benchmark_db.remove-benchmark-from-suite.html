<benchmark_db>.remove-benchmark-from-suite

Synopsis

<benchmark_db>.remove-benchmark-from-suite "suite-name" ("benchmark-name" ... | list of "benchmark-name")

Description

To a specified suite-name remove one or more benchmark-name from it.

Important note: Removing a benchmark from a suite affects the suite's calculated score, just as adding one does.

For example, if the removed benchmark had shown greater improvement compared to others in the suite, the overall score will decrease. This is because the suite's score reflects the relative performance of all included benchmarks.
