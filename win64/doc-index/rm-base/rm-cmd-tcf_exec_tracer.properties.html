<tcf_exec_tracer>.properties

Synopsis

<tcf_exec_tracer>.properties [processor] [trace-memory-access] [trace-exceptions] [trace-instructions] [trace-registers] [disassembly] ([ "address-types" ... ] | list of "address-types")

Description

This command updates and shows tracer properties. Set processor to select processor to trace. Set trace-memory-access to enable or disable tracing of memory access. Set trace-exceptions to enable or disable tracing of exceptions. Set trace-instructions to enable or disable tracing of instructions. Set trace-registers to enable or disable tracing of registers. Set disassembly to enable or disable collection of disassembly as part of instruction tracing. Change address types in traces by setting address-types to any combination of virtual, physical or linear.

Provided By

tcf-agent
