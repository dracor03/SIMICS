<benchmark_db>.add-session-annotation

Synopsis

<benchmark_db>.add-session-annotation session-id "annotation"

Description

Add a user annotation to a specific session. This serves as a comment for the session and is displayed in the output of <benchmark_db>.list-session-scores. The session-id argument specifies the unique session number to annotate. The annotation argument is a string containing the comment to associate with the run. Multiple annotations can be added to the same session; they will be separated by new lines.
