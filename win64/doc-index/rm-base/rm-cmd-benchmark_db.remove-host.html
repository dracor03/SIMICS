<benchmark_db>.remove-host

Synopsis

<benchmark_db>.remove-host "host-name" [-force]

Description

Remove the host-name to the database. This also means that all benchmark runs on this host will be removed, so only use this when the results are not interesting anymore. If there are benchmark runs associated to the host, the -force flag must be used to remove the host name and the associative runs.
