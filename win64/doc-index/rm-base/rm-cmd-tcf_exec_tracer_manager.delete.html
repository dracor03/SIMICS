<tcf_exec_tracer_manager>.delete

Synopsis

<tcf_exec_tracer_manager>.delete (object|-all)

Description

Delete the tracer or traces identified by the arguments.. Select tracers to delete by using object to select tracer by object name, or -all to select all tracers.

Provided By

tcf-agent
