<benchmark_db>.remove-session-annotation

Synopsis

<benchmark_db>.remove-session-annotation [annotation-id]

Description

Removes a specific user annotation from a session. Since multiple annotations can exist for the same session, the annotation-id argument specifies which annotation to remove.
