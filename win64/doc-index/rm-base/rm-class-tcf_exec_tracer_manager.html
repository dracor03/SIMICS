tcf_exec_tracer_manager

Description

This class is used as a parent object of, and has commands for managing TCF execution tracer objects (tcf_exec_tracer).

Interfaces Implemented

conf_object, log_object

Notifiers

cell-change
Notifier that is triggered after the object's cell was changed.
object-delete
Notifier that is triggered just before Simics object is deleted.
queue-change
Notifier that is triggered after the object's clock was changed. New clock can be obtained with the SIM_object_clock function.

Commands for this class

  • delete – delete the tracer or traces identified by the arguments
  • disable – disable tracing
  • enable – enable tracing
  • new – create a new TCF execution tracer
  • status – print status of the object

Provided By

tcf-agent
tcf_exec_tracer tcp-server
