<benchmark_db>.remove-benchmark

Synopsis

<benchmark_db>.remove-benchmark "benchmark-name" [-force]

Description

Remove the benchmark-name from the database. This also means that all runs on this benchmark will be removed, so only use this when the results are not interesting anymore. If there are runs associated to the benchmark, the -force flag must be used to remove both benchmark and runs.
