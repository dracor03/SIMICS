<benchmark_db>.import-json

Synopsis

<benchmark_db>.import-json (json-files ... | list of json-files) [session-id]

Description

Take an existing set of json-files and import the files into the database. If session-id is specified, the corresponding session must have already been created, otherwise the run will be an individual run, not part of a benchmark-session.
