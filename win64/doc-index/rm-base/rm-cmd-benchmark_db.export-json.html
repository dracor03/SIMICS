<benchmark_db>.export-json

Synopsis

<benchmark_db>.export-json json-file [run-id]

Description

Extract the detailed run-information for a specific run-id and write it to the new json-file.

The entire json file for a run is stored compressed into the database. This file contains much more details of the run than what is easily accessed from the database.

Provided By

benchmark-database
