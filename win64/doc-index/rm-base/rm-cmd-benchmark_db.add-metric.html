<benchmark_db>.add-metric

Synopsis

<benchmark_db>.add-metric ([ "probe-names" ... ] | list of "probe-names") [-update]

Description

Adds the specified probe-names as a metric in the database. This means this value will be stored in the database for quick access. The -update switch can be used to retrieve the probe values from the stored json files, exposing the metric in older runs. If there are many runs in the database, this can take some time.
