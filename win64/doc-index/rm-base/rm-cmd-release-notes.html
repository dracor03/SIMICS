release-notes

Synopsis

release-notes ["package"] [-all] [-v]

Description

List release notes for packages since the previous versions installed. If a package name is provided using the package argument, then consider only that package, otherwise consider all packages. Nothing is displayed for packages without release note files or for packages installed for the first time. The -all flag adds older release notes to the output. The -v flag turns on verbose output where information on packages without release note files is included.
