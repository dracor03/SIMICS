<benchmark_db>.add-benchmark

Synopsis

<benchmark_db>.add-benchmark "benchmark-name"

Description

Add a benchmark-name to the database. This is mostly for testing purposes, since an imported run of a new benchmark, will automatically add the new benchmark name to the database itself.
