ai-mode

Synopsis

ai-mode [-fresh] ["model"] [session] [-no-log]

Description

Switch to AI mode in the current interactive command line. In AI mode, indicated by the ?>>> prompt, each line of input is sent to a GitHub Copilot agent via the gh copilot CLI tool. The agent can answer questions about Simics and help with debugging and development tasks. Use Ctrl-D to return to CLI mode.

Use -fresh to start a new chat session instead of resuming the most recent one.

Use the session argument to resume a specific session by number or session ID. Run list-ai-sessions to list available sessions. Example: ai-mode session = 2.

Use the model argument to select a specific model, e.g., ai-mode "claude-opus-4.6". This sends a /model command to the agent at the start of the session. If no model argument is given, the prefs.ai_agent_model preference is used as the default. If that is also unset, the agent's default model is used.

Once inside ai-mode you can get a list of models by asking:

simics?>>> which models are available

And the agent should provide you with available models. Use the /model command to switch model at any time, e.g., /model claude-opus-4.6

By default, all Simics log messages are captured to a temporary file while AI mode is active, so that the agent can inspect them when diagnosing problems. Use -no-log to disable this.

Prerequisites

This command requires the GitHub CLI with the Copilot extension installed and authenticated. To set it up:

  • Install the GitHub CLI: https://cli.github.com/
  • Authenticate: gh auth login
  • Enable Copilot: gh copilot (or gh extension install github/gh-copilot for gh versions older than 2.86)
  • Verify it works: gh copilot --help

    • A GitHub Copilot license (individual, business, or enterprise) is required.
