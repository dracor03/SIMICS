print-target-info

Synopsis

print-target-info [-include-empty-info-blueprints]

Description

Prints a summary of the target machines of the configuration, similar to what is presented in the GUI.

If the flag -include-empty-info-blueprints is given, blueprints with no machine information will also be included.
