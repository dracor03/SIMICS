create-qsp-nic-comp

Synopsis

create-qsp-nic-comp ["name"] ["lan_bios"] ["mac_address"]

Description

This command creates a non-instantiated component of the class qsp_nic_comp.

The class description for the qsp_nic_comp class: PCIe NIC for the QSP (based on ICH10 LAN)

name is Optional
If not specified, the component will get a class-specific default name.

lan_bios is Optional
The Expansion ROM BIOS file for the ICH10 LAN.

mac_address is Optional
Mac address ('XX:XX:XX:XX:XX:XX' string)
