1.1 Command Categories

1.1.1 Components

  • create-chassis-qsp-x86 – create a non-instantiated chassis_qsp_x86
  • create-chassis-x58-ich10 – create a non-instantiated chassis_x58_ich10
  • create-motherboard-x58-ich10 – create a non-instantiated motherboard_x58_ich10
  • create-qsp-nic-comp – create a non-instantiated qsp_nic_comp
  • create-qsp-usb-comp – create a non-instantiated qsp_usb_comp
  • new-chassis-qsp-x86 – create an instantiated chassis_qsp_x86
  • new-chassis-x58-ich10 – create an instantiated chassis_x58_ich10
  • new-motherboard-x58-ich10 – create an instantiated motherboard_x58_ich10

1.1.2 Instrumentation

  • <sample_core_timing_tool>.add-instruction-class – add instruction class with ipc and cdyn adjustments
  • <sample_core_timing_tool>.add-instrumentation – add instrumentation
  • <sample_core_timing_tool>.delete – deletes instrumentation tool
  • <sample_core_timing_tool>.disable-instrumentation – disable instrumentation
  • <sample_core_timing_tool>.enable-instrumentation – enable instrumentation
  • <sample_core_timing_tool>.info – print information about the object
  • <sample_core_timing_tool>.list-instruction-classes – list instruction classes
  • <sample_core_timing_tool>.list-metrics – list metrics of the simple performance model
  • <sample_core_timing_tool>.list-performance-metrics – list performance metrics from the model
  • <sample_core_timing_tool>.list-providers – list-provider objects
  • <sample_core_timing_tool>.remove-instruction-class – remove instruction class
  • <sample_core_timing_tool>.remove-instrumentation – remove instrumentation
  • <sample_core_timing_tool>.set-activity-per-read – set extra activity per read operation
  • <sample_core_timing_tool>.set-activity-per-write – set extra activity per write operation
  • <sample_core_timing_tool>.set-background-activity-per-cycle – set background activity per cycle
  • <sample_core_timing_tool>.set-base-activity-per-instruction – set activity per instruction
  • <sample_core_timing_tool>.set-base-cycles-per-instruction – set base cycles per instruction
  • <sample_core_timing_tool>.set-cycles-per-read – set extra cycles per read operation
  • <sample_core_timing_tool>.set-cycles-per-write – set extra cycles per write operation
  • new-sample-core-timing-tool – create a new sample_core_timing_tool object
