pci_upstream_dispatcher

Description

Device to send upstream traffic to remap units.

Interfaces Implemented

conf_object, log_object, transaction_translator, translation_flush

Connects

default_remapping_unit (optional)
Optional interfaces: io_memory, memory_space, port_space, ram, rom, transaction, transaction_translator, translator
gfx_remapping_unit (optional)
Optional interfaces: io_memory, memory_space, port_space, ram, rom, transaction, transaction_translator, translator
interrupt (optional)
Required interfaces: pci_interrupt

Notifiers

cell-change
Notifier that is triggered after the object's cell was changed.
object-delete
Notifier that is triggered just before Simics object is deleted.
queue-change
Notifier that is triggered after the object's clock was changed. New clock can be obtained with the SIM_object_clock function.
state-change
Notifier on potential DML state change

Port Objects

port.msg
pci_upstream_dispatcher.msg – legacy PCI INTx message to pci_interrupt converter

Commands for this class

  • info – print information about the object
  • status – print status of the object

Attributes

default_remapping_unit
Optional attribute; read/write access; type: o|[os]|n
Default DMA remapping unit

Optional interfaces: io_memory, memory_space, port_space, ram, rom, transaction, transaction_translator, translator

fwd_msg_to_iommu
Optional attribute; read/write access; type: b
Route messages to the IOMMU
gfx_objs
Optional attribute; read/write access; type: [o*]
List of configuration objects from which transactions will be remapped using the graphics remapping unit
gfx_remapping_unit
Optional attribute; read/write access; type: o|[os]|n
Graphics DMA remapping unit

Optional interfaces: io_memory, memory_space, port_space, ram, rom, transaction, transaction_translator, translator

interrupt
Optional attribute; read/write access; type: o|[os]|n
Target to receive PCIe Legacy Interrupts

Required interface: pci_interrupt
