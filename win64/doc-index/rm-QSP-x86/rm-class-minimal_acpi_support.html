minimal_acpi_support

Description

The minimal_acpi_support provides an ACPI timer, shutdown detection, some "Flash"and an SMM trigger mechanism.

Interfaces Implemented

conf_object, log_object

Notifiers

cell-change
Notifier that is triggered after the object's cell was changed.
object-delete
Notifier that is triggered just before Simics object is deleted.
queue-change
Notifier that is triggered after the object's clock was changed. New clock can be obtained with the SIM_object_clock function.
state-change
Notifier on potential DML state change

Attributes

cpus
Required attribute; read/write access; type: [o*]
CPUs receiving direct pin connections for SMI
internal_flash_size
Required attribute; read/write access; type: i
Size of internal flash
pm_timer_notify_count
Pseudo attribute; read/write access; type: i
Number of acpi-pm-timer-read notifications to send on each read of the ACPI PM timer. Zero, the default, disables the notifications entirely. Intended for benchmarking the cost of the notifier mechanism; it has no functional effect on the model.
