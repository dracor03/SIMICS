create-qsp-usb-comp

Synopsis

create-qsp-usb-comp ["name"]

Description

This command creates a non-instantiated component of the class qsp_usb_comp.

The class description for the qsp_usb_comp class: PCIe USB host for the QSP (based on ICH10 EHCI/UHCI)

name is Optional
If not specified, the component will get a class-specific default name.

Provided By
