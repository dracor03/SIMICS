pci_cf8_cfc_handler

Description

Simple device to handle indirect PCI configuration accesses via IO ports CF8 (address) and CFC (data).

Interfaces Implemented

conf_object, log_object

Connects

downstream_target (optional)
Required interfaces: pcie_port_control
Optional interfaces: io_memory, memory_space, port_space, ram, rom, transaction, transaction_translator, translator

Notifiers

cell-change
Notifier that is triggered after the object's cell was changed.
object-delete
Notifier that is triggered just before Simics object is deleted.
queue-change
Notifier that is triggered after the object's clock was changed. New clock can be obtained with the SIM_object_clock function.
state-change
Notifier on potential DML state change

Port Objects

bank.io_regs
pci_cf8_cfc_handler.io_regs

Commands for this class

  • info – print information about the object
  • status – print status of the object

Attributes

downstream_target
Optional attribute; read/write access; type: o|[os]|n
PCIe Downstream Target

Required interface: pcie_port_control

Optional interfaces: io_memory, memory_space, port_space, ram, rom, transaction, transaction_translator, translator
