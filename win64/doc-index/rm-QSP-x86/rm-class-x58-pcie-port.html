x58-pcie-port

Description

PCI Express Root Port unit in the Intel® X58 Express Chipset.

Interfaces Implemented

conf_object, log_object, pcie_device, pcie_hotplug_events, transaction_translator, translation_flush

Connects

clkreq (optional)
Required interfaces: signal
upstream_target (optional)
Required interfaces: pcie_map
Optional interfaces: io_memory, memory_space, pcie_link_control, port_space, ram, rom, transaction, transaction_translator, translator

Notifiers

cell-change
Notifier that is triggered after the object's cell was changed.
object-delete
Notifier that is triggered just before Simics object is deleted.
queue-change
Notifier that is triggered after the object's clock was changed. New clock can be obtained with the SIM_object_clock function.
state-change
Notifier on potential DML state change
