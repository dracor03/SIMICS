3 Layout and lexical details

The indentation step is 4 spaces. Do not use tabs. Keep lines shorter than 80 characters.

Put a space:

  • around binary operators such as +
  • after but not before comma, colon or semicolon
  • after the assert statement
  • between a keyword (such as while) and its argument

Put no space:

  • before comma, colon or semicolon
  • immediately inside parentheses, braces or brackets
  • between the function name and the opening parenthesis in a function call

It is customary to not put spaces around = inside parameter lists of function calls and definitions, but it is permitted to use a single space on each side if that makes the code look nicer:

draw(figure, options =None, paper= "A4")          # BAD
draw(figure, options=None, paper="A4")            # GOOD
play(frequency = f0 + delta, duration = d + 0.5)  # GOOD

Put spaces around colons when used in sliced indexing, but not where an index is omitted:

a[i + 1:j + 5]        # BAD
a[i + 1 : j + 5]      # GOOD

a[ : j + 5]   	      # BAD
a[:j + 5]     	      # BAD
a[: j + 5]    	      # GOOD

a[i + 1:]             # BAD
a[i + 1 : ]           # BAD
a[i + 1 :]            # GOOD

a[i + 1:j + 5:s]      # BAD
a[i + 1 : j + 5 : s]  # GOOD

a[i + 1::s]           # BAD
a[i + 1 : : s]        # BAD
a[i + 1 :: s]         # GOOD

If neither index contains spaces, the spaces around colon may be omitted, per PEP8:

a[i : j]         # OK
a[i:j]           # OK
a[i + c:j + d]   # BAD

To fold long lines, it is usually better to use parentheses rather than backslashes. I.e., instead of:

result = extremely_long_expression \
         + another_very_long_expression \
         + yet_another_long_expression

please use:

result = (extremely_long_expression
          + another_very_long_expression
          + yet_another_long_expression)

Long lines are broken before binary operators, not after.

Avoid C-isms such as parentheses around the condition of if statements or terminating semicolons.

In multi-line lists, put a trailing comma after each element, even the last one:

muppets = [
    "Kermit",
    "Miss Piggy",
    "Gonzo",
]

This way, there is less of a risk of forgetting a comma when adding an element at the end, and diffs and merges become neater.
