probes

Name

probes — Probe APIs usable both inside and outside Simics.

Synopsis

Python

import probes

Description

Importing this package does not enable the Simics probes framework. Pure probe types and formatting utilities are always available. Runtime queries return empty results until enable-probes installs a backend. Simics-specific runtime APIs are exposed only when imported inside Simics.

probes.get_all_probe_kinds

Synopsis

probes.get_all_probe_kinds()

Description

Gets all registered probe-kinds in the system.

Returns all registered probe-kinds in the system. The probe-kind is the unique probe identifier, not including the objects associated with it.

See Also

probes.get_probes, probes.get_all_probes

probes.get_all_probes

Synopsis

probes.get_all_probes()

Description

Gets all ProbeProxy instances.

Returns all Python ‘ProbeProxy’ objects that exists currently. These objects can be used to access the probe interfaces in a convenient way by using methods in them.

See Also

probes.get_all_probe_kinds, probes.get_probes

probes.get_probes

Synopsis

probes.get_probes(kind)

Description

Gets hold of all ProbeProxy instances implementing a specific probe-kind.

Returns the Python ‘ProbeProxy’ objects, for probes matching the specific probe-kind. These objects can be used to access the probe interfaces in a convenient way by using methods in them.
