QSP-CPU Release Notes

This document contains release notes for the package QSP-CPU (package number 8112) for Simics 7. The release notes describe new features, bug fixes, and other changes.

Changes Since Version 7.0.0

The following is a list of changes since the initial 7.0.0 release.

7.36.0 (build 7213)

New features and bug fixes

  • Implemented Processor Trace trace-address pre-translation (TAPT), so EPT violations on trace output are reported before the output region is used. This also fixes a crash caused by recurring EPT violation.

x86 Generic

  • The print-cpuid command has been extended (fixes SIMICS-17215):
    • Optional subleaf argument limits the output to a single subleaf, and the subleaf is printed in hexadecimal, like the leaf.
    • Optional register argument prints and returns the value of a single CPUID output register.
    • The output is rendered with the Simics table formatting. The command return value changed accordingly, from a list of preformatted lines to a list of rows.

7.35.0 (build 7211)

x86 Generic

  • Fixed a bug causing sysexit incorrectly returning to 64bit code when REX.W prefix was used (fixes SIMICSTS-1850).
  • Fixed SAI to check only BIOS_DONE bit 0 instead of the whole MSR value.

7.34.0 (build 7209)

x86 Generic

  • Eliminated spurious page faults while running with VMP that could cause incorrect virtual time bookkeeping.

7.33.0 (build 7207)

New features and bug fixes

  • Fixed Processor Trace still running after reset
  • CPU components no longer set bootstrap processor flag for unpowered cores.

x86 Generic

  • Removed destination operand side effects from CVTPS2PD instruction when an exception is raised (related HSD-14028615876).
  • Added missing logic to handle overlapping destination and source operands in emulation of CVTPS2PD instruction (fixes HSD-14028615876).
  • Added missing scaling of displacement to Intel® Advanced Vector Extensions 512 (Intel® AVX-512) variant of VEXTRACTPS (fixes HSD-14028584368).

7.32.0 (build 7202)

x86 Generic

  • CPUID.(EAX=24H, ECX=01H):ECX[2] is now exposed and supported as AVX10_V1_AUX under AVX10.2 environments (fixes CRSQ-2119)

7.31.0 (build 7198)

x86 Generic

  • Added VMP support for virtualization of Intel® Flexible Return and Event Delivery (Intel® FRED). Note, legacy instructions used for ring transitions such as far-CALL, IRET, far-JMP, far-RET and SWAPGS will not behave as expected with Intel® FRED enabled.
  • Access size to LTCTRLSTS register has been corrected to 4B.

7.30.0 (build 7194)

New features and bug fixes

  • Fixed triple fault behavior: processor now goes to Shutdown activity state.

x86 Blueprint

  • Extended blueprints to match legacy components.

x86 Generic

  • Fixed bug causing spurious Intel® Control-Flow Enforcement Technology (Intel® CET) #CP(ENDBR) exceptions.
  • MSR 0x982 IA32_TME_ACTIVATE now uses the uncore as storage instead of local CPU storage. This ensures the package-scope MSR is reset correctly when the BSP is disabled.
  • Fixed a bug in the class_disassembly interface handling where disassembling instructions that check MSR values would result in a crash (fixes HSD-15019734260).

7.29.0 (build 7188)

New features and bug fixes

  • Correctly disassemble instruction Set AL Based on Carry Flag.

7.28.0 (build 7187)

New features and bug fixes

  • Allow MSR 0x773 write before HWP_ENABLE is set (HSD-14028250791).

x86 Generic

  • GETSEC broadcast logic now skips logical processors in the Shutdown activity state, so that such processors are no longer sent the SMX broadcast signal.

7.27.0 (build 7182)

x86 Blueprint

  • The blueprints now respect the use_vmp configuration parameter.

x86 Generic

  • The BIOS guard now uses helper objects of the crypto_engine_openssl class, instead of the crypto_engine_rsa class. The package now requires version 7.21.0 or higher of package 1030.

7.26.0 (build 7180)

x86 Generic

  • The BIOS guard now uses the rsa_v2 interface instead of the rsa interface.

x86 public 64-bit blueprints

  • Blueprint implementation of public Intel® 64 processor components. All processor classes from x86-public64-comp are now available as blueprint functions with legacy component adapter support.

7.25.0 (build 7174)

CPU generic

  • Fixed a memory leak in the event queue handling.

x86 Generic

  • Add CPUID fuse check for MSR 0x982 TME_ACTIVATE

7.24.0 (build 7171)

x86 Generic

  • Added new VMP backoff mechanism used to prevent execution of instructions not supported by the host CPU. Can significantly improve performance in scenarios such as running Intel® Advanced Vector Extensions 512 (Intel® AVX-512) workloads on a host lacking support for the same technology.

7.23.0 (build 7164)

CPU generic

  • The package now requires Simics-Base version 7.89.0 or later.

x86 Generic

  • Added support for acceleration of Intel® Control-Flow Enforcement Technology (Intel® CET) Shadow Stack using VMP. Requires vmxmon 1.16.20.
  • An error is logged when SMRAM reading or writing fails via the x86_smm_state interface.
  • Updates to PKRU coming from XRSTOR operation will now correctly flush TLB entries to prevent using stale read-write permissions for translations with changed keys.

7.22.0 (build 7161)

x86 Generic

  • Memory type calculation is now always done for memory accesses. Corresponding fields in CPU’s memory transactions are always filled. Attribute enable_effective_memory_type_calculation no longer has an effect on the calculation of memory types; it still affects a handful of target instructions using non-temporal accesses.
  • Fixed UD1 exception priority regression (fixes HSD-21044489242).
  • Fixed CAR data corruption when BIOS reprograms MTRRs for an already active CAR region with no underlying RAM. Previously, remounting copied 0xFF bytes from unmapped memory into CAR, overwriting valid data. The fix detects whether real RAM or ROM backs the CAR region and skips the data copy when it does not. Still a problem for CAR regions with valid underlying memory.
  • VCR accesses through the MSR and I/O space now use transaction_t instead of memory_transaction_t. The transactions have the x86_msr_number ATOM attached which allows the handlers to know which MSR is being accessed that caused the VCR access (fixes SIMICSTS-1768). The memory space that’s attached to the msr_space attribute on x86-* CPUs must now implement the transaction interface.

7.21.0 (build 7157)

7.20.0 (build 7156)

CPU generic

  • Instrumentation that only increments counters (such as instruction-histogram) now runs slightly faster and consumes significantly less memory, improving performance in workloads with large code footprints such as operating system boots.

x86 Generic

  • LTCTRLSTS MSR write access masks were aligned with documentation. In particular, bit 4 SCHECK_PASS was enabled (fixes HSD-18044244311).

7.19.0 (build 7151)

Common

  • The signing certificate on Simics packages has been updated.

7.18.0 (build 7149)

x86 Generic

  • Fixed VAB authentication issue in ACM validation.
  • Optimized the PC (program counter) bootstrap code in the interpreter (rebind), by using our page cache for code. If a translation exists, we can immediately use it.

7.17.0 (build 7146)

New features and bug fixes

  • Removed obsolete cpuid_cr_iface attribute.

x86 Generic

  • The following attributes that could be used to force model behavior to become incompatible with Intel® 64 architecture are now deprecated: null_clear_base_and_limit, debug_len_10b_8_bytes, lar_ldt_lm_invalid, load_far_ptr_64, skip_canonical_logical_check, mov_default32, seg_push_zero_pad, sp_mask_non64. Writing to them will have no effects.

7.16.0 (build 7144)

CPU generic

  • Added ports physical_memory_inspection and logical_memory_inspection to inspect the physical memory attached to the processor. These ports add the architectural atoms representing the current state of the processor before forwarding the transaction to the physical_memory (fixes SIMICS-22568).

x86 Blueprint

  • Fixed a bug with instantiation of public cores due to removal of sgx_crypto_* attributes.

x86 Generic

  • Made all deprecated pseudo-attributes internal.
  • Logging of VMP return events is made consistent with documentation strings of VMP return codes used in probes.

7.15.0 (build 7142)

CPU generic

  • Fixed an invalid dependency from CPU models using the new simgen to the old simgen, causing problems building the CPU model on systems without 32-bit support.
  • Instruction breakpoints for physical addresses reported the address of the beginning of the instruction even though the breakpoint starts on the second half of a page crossing instructions. This is different from breakpoints triggered by transactions sent to the memory system, which do not know about the beginning of the instruction. This bug is now fixed, and only the part which actually crosses the breakpoint is reported, bug SIMICS-9695.

Flexible Return and Event Delivery (FRED)

  • According to FRED 9.0, in presence of supervisor indirect branch tracking, FRED event delivery does not enter WAIT_FOR_ENDBRANCH state.

Intel® 64 public cores

  • Attributes for following MSRs were renamed to msr_XXXh: 0x615, 0x412, 0x413.
  • Intel® Software Guard Extensions (Intel® SGX) and Intel® Trust Domain Extensions (Intel® TDX) support was removed, since not all dependencies for those features are shipped.
  • msr-get, msr-set, msr-read and msr-write commands now support name argument.

New features and bug fixes

  • Opcode bytes printed by disassemble command are now correctly fetched in the case when the target instruction opcode sequence crosses virtual page boundary.
  • Report separate VMP exit codes for various no-progress and no-action-needed events instead of one ambiguous VMRET_NOP. This addresses SIMICSTS-1636.
  • Introduce exponential backoff for VMP no-progress situations. This provides a better solution to SIMICS-23084.
  • Introduce exponential backoff for VMP no-progress situations. This provides a better solution to SIMICS-23084.

x86 Generic

  • C‑state transitions have been made faster. Systems that have a large number of CPU cores within the processor package will benefit the most.
  • read-cpuid command was added. Global version of print-cpuid command was added.
  • The TLB model x86ex_tlb did not flush internal CPU caches correctly when a mapping was updated, this is now fixed. It also now reclaims the internal memory correctly if the object is deleted.
  • The pregs command has been updated with a new way of presenting the bit fields of the different control registers. Now lines are used to connect the bits with the field names which, makes it more readable.
  • Fix sporadic instability when handling instructions crossing page boundaries.
  • Fix sporadic instability causing the wrong instruction to be executed.
  • Fix inconsistent reading of last-branch records (LBR state) values when accessed via MSR IA32_LBR_x_INFO for supported counters (fixes HSD-13014068634).
  • Made MSR IA32_DEBUGCTL available if architectural Last Branch Records (LBRs) is supported, preventing incorrect unimplemented logging.
  • The x86-bare module has been fixed so that it used the correct tlb, compatible with the core.
  • Prevent out of bounds read in AVX2 gather/scatter instructions (fixes SIMICSTS-1665).
  • Ensure MSR 0x981 IA32_TME_CAPABILITY is only available when Intel® Total Memory Encryption (Intel® TME) is supported (partial fix for HSD-15018262218).
  • Fixed a bug when a physical breakpoint is removed from the second part of a page crossing instruction, previously Simics could crash if the address of the (removed) breakpoint was reached again, bug HSD-15017812702.
  • Fix SIMICSTS-1633 “Assertion error when updating vm_disable_reasons stats”.
  • Added Hypervisor CPUID Leaf 0x4fffffff for SIMFLAG check of Running in Simics Environment for FW/SW.
  • Added four new Xed classifications for an instruction in the xed_access interface: Xed_Iclass, Xed_Extension, Xed_IsaSet, and Xed_Category.
  • Removed support for loading MCHECK using the sgx_mcheck_module attribute. All virtual platforms have migrated to using the mcheck_section attribute by now.

7.12.0 (build 7093)

CPU generic

  • Fixed a rare bug where the results of Just-In-Time (JIT) compiled code could be inconsistent with those produced by the interpreter. This inconsistency occurred when the memory hierarchy replaced the value to be written, which was incorrectly ignored by the JIT compiler. This issue has now been corrected (fixes HSD-14024141137).
  • New probes were added to measure the wall clock time spent in uncore simulation. Currently this is only for memory mapped IO activities. The new probe-kinds are: cpu.time.uncore, cell.time.uncore, and sim.time.uncore.

Intel® QSP3 core

  • Initial release of the Intel® QSP3 core. It is based on the Golden Cove core with CPUID overrides to make it run more in VMP accelerated mode for e.g. Linux boot.

New features and bug fixes

  • Removed legacy MSR commands: trace-msr, trace-msr-read, break-msr, break-msr-read. MSR breakpoints (bp.msr) are used for this functionality instead
  • Added class_disassembly interface (fixes SIMICS-16975)
  • Support relaxed error code checking in vmx event injection (HSD-14025062355).
  • EPT violation exit qualifier set bit 0 and 1 correctly (HSD-15015916629).
  • VMP session’s return code VMRET_NOP is now treated as eligible for VMP backoff. This addresses SIMICS-23084, where a suspected host IRQ overload causes no-progress in simulation.
  • Implemented return compression for Processor Trace (HSD-18041551993).
  • In 64-bit mode, do not allowed CR0.PG to be cleared.

x86 Generic

  • The near_branches_64 attribute has been deprecated in all x86 models, this was an AMD64 compatible attribute for changing the behavior of near branches for 16 bit operand size. Setting the attribute has now no effect, and its default value has changed to TRUE.
  • Fixed a memory leak related to the one in HSD-22021270646.
  • Fixed a memory leak, HSD-22021270646.

CPU generic

  • transaction_translators that needs to perform side effects on a page access can now deny a inquiry direct memory lookup from CPUs. The CPU will follow up with a real access and then retry the direct memory lookup. Before this change, such behavior by transaction_translator would significantly degrade the runtime Simics performance (fixes SIMICS-19940).

New features and bug fixes

  • Instead of ambiguous “64-bit mode” used before, print-registers is updated to mention specifically 4- and 5-level paging modes.

7.1.0 (build 7030)

CPU generic

  • The size of the module global JIT area has increased from 64MB to 256MB. Workloads with very large instruction footprint, could fill up the entire JIT code area, resulting in a flush and slow recompilation.
  • Linux only: If the kernel supports Transparent Huge Pages (THP), the JIT code area now makes use of 2MB TLB mappings. This could slightly increase execution performance.

Common

  • The signing certificate on Simics packages has been updated.

Flexible Return and Event Delivery (FRED)

  • Record event data injected at VM-entry over NMI source information in FRED return stack. This is according to FRED 5.0 specification (chapter 9.5.4).
  • Fixed a bug where the NMI source was not recorded if an NMI occurred in VMX non-root mode with FRED disabled in the guest (fixes HSD-22020188866).

Intel® 64 public cores

  • msr-get, msr-set, msr-read and msr-write commands were added.
  • print-msrs command was added.
  • Removed incorrect enumeration of Intel® SGX from the x86-alderlake CPU class.

New features and bug fixes

  • Corrected the DWARF IDs used by the R16-R31 registers added by Intel® Advanced Performance Extensions (Intel® APX) (fixes HSD-18039292554).
  • Fixed a situation when a target using 5-level EPT paging caused VMP to misinterpret it as 4-level EPT paging (fixes HSD-15016077738).
  • Honor PT2GPA and EPT on the first Processor Trace packets when tracing starts disabled due to context.
  • Fixed a bug in ia32_spec_ctrl MSR handler that caused some side effects when no side effects access was used (fixes HSD-14022136686).
  • Fixed a bug that could cause incorrect state component offsets when saving compacted XSAVE state if non-saved aligned components were included (fixes HSD-14022348780).
  • Add SEAM safe address checks for RTIT. Intel® TDX key bits cannot be set in mask or address when it is outside the SEAM (fixes HSD-18020627633).
  • Ensure that the MXCSR mask always reports the same value in all simulation engines on Intel® 64 Architecture targets (fixes HSD-15015935589).
  • Fix CR4.FRED handling upon GETSEC[ENTERACCS/EXITAC] (fixes HSD-18038889559).
  • Run single_step if inside opcode that clears TF. Fixes one of the problems reported in (fixes HSD-15015891903).
  • De-enumerate MPX on all CPU models that claimed to support it. MPX has been officially deprecated since 2019. It has been operating as NOPs in Simics since 2022. It is no longer enumerated in CPUID (fixes HSD-1309925665 and HSD-18038801416.
  • Fix IDTR:LIMIT handling upon GETSEC[ENTERACCS/EXITAC] (fixes HSD-18038890251).
  • Clear pending debug exception on cpu reset. Fixes an issue where old pending debug exception could be delivered after reset.
  • The rflags register is now exposed to TCF through the describe_registers interface (fixes HSD-18038862421).
  • Fix calculation of max XSAVE area required in CPUID.0DH.00H:EBX and ECX (fixes HSD-18038659155).
  • Handle VMX injected event while MTF is enabled. Fixes one of the problems reported in (fixes HSD-15015916269).
  • More precise check for reserved bits in CR3. Fixes one of the problems reported in (fixes HSD-15015916269).
  • Fixed crash on cross-page Processor Trace write in VMX mode (fixes HSD-15012410613).
  • Removed a INST_INFO: 0xX debug printout accidentally left in the VM exit code (fixes HSD-14022562102).
  • Handle #DB/#BP when RTM advanced debug enabled. Fixes one of the problems reported in (fixes HSD-15015916269).
  • Use MSR 0x2d9 FUSA_CAPABILITIES fields STARTUP_SCAN_BIST[0] and PERIODIC_SCAN_BIST[4] to determine if SAF is enumerated (fixes SIMICSTS-1318).
  • Correct DR6 register and exit qualifier VMCS field. Bits in DR6 are no longer cleared after every #DB, and VCMS field exit qualifier will have all bits correctly set if more than 1 exception scenario happens on the same cycle. This fixes one of the problems reported in (fixes HSD-15015916269).
  • Use MSR 0x2d9 FUSA_CAPABILITIES.SBFT[8] to determine if SBFT is enumerated (fixes SIMICSTS-1316).
  • Change Processor Trace packet order so MODE.Exec is in between coupled FUP and TIP.
  • Fix writing to MSR ACTIVATE_SCAN (0x2c6). Start using mask taken from register drop, instead of hardcoded value (fixes SIMICSTS-1317).
  • Fix writing to MSR ACTIVATE_SBFT (0x2bc). Start using mask taken from register drop, instead of hardcoded value (fixes HSD-18020627607).
  • Set EXT bit in the interrupt error code correctly (fixes HSD-15013738894).
  • Implement Processor Trace TIP package generation scenarios: IRET, SYSENTER/SYSEXIT, SYSCALL/SYSRET, JMPABS.
  • Do not report mixing reset flows for unrelated processors (fixes SIMICSTS-1305).
  • Fix Processor Trace TNT branch taken detection in case where taken and not-taken destinations differ only by page part of the address.
  • Fix writing invalid page part of the address to LBR_x_TO MSRs (fixes HSD-18034413312).
  • Fix invalid IP payload generation in Processor Trace TIP packet when near return crosses page boundary (fixes HSD-18035194187).
  • Implement 64-bit IP payload for Processor Trace FUP, TIP and TIP.PGE packets.
  • Add information about linear address masking (LAM) in 4- and 5-level paging modes for user code (LAM_U48 and LAM_U57) to layout of CR3 available via describe_registers interface (fixes HSD-18031041673).
  • Add TNT buffer flush on Processor Trace PSB packet (fixes HSD-18035192151).
  • Change Processor Trace CYC packet format to match the specification.
  • Add SEAM safe address check for APIC_BASE. Upper bits cannot be set in address when it is outside the SEAM (fixes SIMICSTS-1259).
  • Add SEAM safe address check for TME_EXCLUDE. Upper bits cannot be set in address when it is outside the SEAM (fixes SIMICSTS-1261).
  • Revert SEAM safe mask check for PRMRR. Following the documentation, PRMRR_MASK ignores bits above physical size in calculations (fixes HSD-14022009940).
  • Add clearing of CPU caches at SMM exit to protect SMM-private memory from being accessible outside SMM (fixes HSD-15014556607).
  • Fixed handling of SIPI signals during Application Processor startup (fixes HSD-15015543927).
  • Add SEAM safe address check for HW_FEEDBACK_PTR. Intel® TDX key bits cannot be set in address when it is outside the SEAM (fixes SIMICSTS-1258).
  • Implement Processor Trace Paging Information Packet generation (fixes HSD-18021309126).
  • Fixed delivery of INIT signals received in Virtual Machine Extensions (VMX) root mode (fixes HSD-13011704431).
  • Add SEAM safe address and mask checks for FUSARR. Intel® TDX key bits cannot be set in mask or address when it is outside the SEAM (fixes SIMICSTS-1255).
  • Add SEAM safe address and mask checks for PRMRR. Intel® TDX key bits cannot be set in mask or address when it is outside the SEAM (fixes SIMICSTS-1254).
  • Removed support for usage of final opcodes other than [0x0f, 0x00, 0xc4] from the sgx_mcheck_module attribute.
