30 Introduction

When users write and build Simics modules the compiled modules end up in the user’s project. One of the most reliable ways to distribute a set of files across many users is to create a Customer Package.

A Customer Package is a Simics Package just like any other Simics Package. It is an .ispm file and the only difference compared to other Simics Packages is that it is not published in the Simics package repository.

To install a Customer Package install it with the Intel Simics Package Manager. Go to the Packages tab and select Install Package from File Locations. Then select your package either by giving its path or browsing to it and press the Install Package button to install it.
