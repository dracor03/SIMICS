CLKREQ template

pcie_clkreq

Defines a connect for the CLKREQ output signal of a PCIe Device.

connect clkreq

CLKREQ output signal (active high)

clock_is_required() -> (bool)

Predicate function that determines whether the CLKREQ signal needs to be asserted.

update()

Updates the state of the CLKREQ signal based on the current power management status. This is safe to call even if the signal does not change.
