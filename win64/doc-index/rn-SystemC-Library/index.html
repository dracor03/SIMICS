SystemC™ Library (Package Number 1013) Release Notes

This document contains release notes for the package SystemC™ Library (package number 1013) for Simics 7. The release notes describe new features, bug fixes, and other changes.

Changes Since Version 7.0.0

The following is a list of changes since the initial 7.0.0 release.

7.45.0 (build 7208)

SystemC Library

  • Fixed a bug in PcieMap::del_function leaving a stale PCIe MSG-space mapping behind, which prevented deletion of PcieGasket-based endpoint objects after they were disconnected from the PCIe bus.

7.44.0 (build 7206)

SystemC Kernel

  • Updated the kernel 3.0.0 patch version to 20260925-Intel. Backported Accellera upstream commit 3570c37, removed nonstandard MSVC ostream opfx usage, and added support for building with MSVC 2026.

7.43.0 (build 7200)

Simics Serialization Library

  • Updated to work with GCC 16 and Boost 1.91.0.

SystemC Checkpoint Documentation

  • Migrated the documentation to Markdown

SystemC Checkpoint Library

  • Bumped Boost to 1.91.0. This adds support for GCC 16 and C++20 as well. The requirement of a fixed version has been removed so the user can use any local version of boost newer than 1.83.0 now. It is recommended to use version 1.91.0 though. It is not possible to use the old 1.65.1 anymore.

SystemC Library

  • Fixed SR-IOV VF enablement and disablement for PCIe devices with non-zero device numbers.
  • Fixed a type problem preventing use of C++20.

7.42.0 (build 7184)

SystemC Library

  • Added class-level control of when SystemC end-of-elaboration is triggered via setDeferEndOfElaboration. The default behavior remains legacy-compatible (end-of-elaboration in finalize). Device classes can defer end-of-elaboration to objects_finalized, which allows gaskets to be created in finalize methods of the Adapter’s port objects.
  • Deferred the gasket binding check to the objects_finalized phase. This allows gaskets to be created and bound from within Port::finalize without triggering false missing-gasket errors (fixes SIMICS-23622).

7.41.0 (build 7181)

SystemC Library

  • Improved Adapter validation errors for missing set_gasket calls by reporting the unresolved gasket names in the error message.

7.40.0 (build 7175)

SystemC Interfaces

  • Improved the output formatting of memory-profiler-results by showing human-readable memory usage and using digit-grouped allocation counts for better readability (fixes SIMICS-19537).

7.39.0 (build 7168)

SystemC Library

  • Simplified GCC-to-ABI version mapping by consolidating the mapping into a single Python source.

7.38.0 (build 7164)

SystemC Kernel

  • Updated kernel patch version to 20260601-Intel. Use single-entry cache in sc_simcontext.cpp to avoid repeated unordered_map lookups for Intel extension state.

7.37.0 (build 7160)

SystemC Library

  • Improved simulation scheduling performance by reducing overhead in get_delta method for the common case where time has not advanced since the last clock tick.

7.36.0 (build 7159)

SystemC Library

  • Added extra validation of BAR info during connect of PCIe gasket.

7.35.0 (build 7155)

SystemC Library

  • Fixed SYSTEMC_DEPS_CACHE to support partial kernel version coverage. Users can now provide only the required kernel versions in the cache directory without needing all supported versions. Missing versions are automatically skipped during configuration.
  • Fixed SimicsAdapter binding to prevent incorrect class mapping in multi-class setups (fixes SIMICS-23503).

7.34.0 (build 7151)

SystemC Library

  • Added missing process stack handling to simics2tlm gaskets, fixing the re-entry problem when the process calls wait().

7.33.0 (build 7150)

Common

  • The signing certificate on Simics packages has been updated.

SystemC Library

  • Gate PciExpress on SIMICS_6_API or SHOW_OBSOLETE_API.
  • Adjusted the build-systemc-libraries build script to use the RelWithDebInfo build mode for non-debug builds, to match the previous GNU Make setup. Users that need to build with Release mode should switch to a CMake-only flow.

7.32.0 (build 7148)

SystemC Library

  • The systemc2simics::Signal::set_pin() method now accepts an optional bool initial_value parameter (default false) to set the initial state of the underlying sc_signal<bool>, enabling correct modeling of active-low signals that are deasserted (high) after init.

7.31.0 (build 7147)

SystemC Kernel

  • Updated kernel patch version to 20260317-Intel. Use external data registry instead of embedding members in the sc_simcontext class to improve ABI compatibility.

7.30.0 (build 7146)

SystemC CCI

  • Added support to build CCI with INTC_EXT=0.

SystemC Library

  • Added support to build SystemC CCI with INTC_EXT=0.
  • SystemC checkpointing is now skipped when running the build-systemc-libraries script with INTC_EXT=0.

7.29.0 (build 7145)

SystemC Library

  • Added sized operator delete(void*, std::size_t) and operator delete[](void*, std::size_t) overloads to memory profiling to comply with C++14 standard and fix alloc-dealloc-mismatch errors with GCC 12.

7.28.0 (build 7141)

SystemC Library

  • Improved handling of ProcessStack. Only needed for thread processes.
  • Consolidated C++ ABI version mapping logic into a shared CMake function to avoid duplication across SystemC modules.

7.27.0 (build 7140)

SystemC Library

  • Fixed a bug in ProcessStack::pop() by deferring event notification when kernel is in update phase.

7.26.0 (build 7139)

SystemC Library

  • Fixed ABI version mapping for GCC 13 (corrected from ABI 13 to ABI 14 to match CXXABI_1.3.14).

7.25.0 (build 7136)

SystemC Library

  • CMake minimum version for SystemC is 3.26, now added as an explicit requirement
  • The default SystemC kernel used to build SystemC Library is changed from 2.3.3 to 2.3.4.
  • Moved internal systemc.cmake from Base to the 1013 add-on package.
  • Moved LogStream class from SystemC Library to C++ API. The class is now available in simics/log.h with no API changes.

7.24.0 (build 7135)

SystemC CCI

  • Updated CCI version from 1.0.0 to 1.0.2.

SystemC Library

  • Fix rounding of SystemC timestamp conversion to avoid off-by-one errors when casting scaled seconds to integer.

7.23.0 (build 7133)

SystemC Library

  • Removed the following unused and deprecated flags from the build script: -u/--unittests, -m/--make and -std/--cxx-standard. Added a new flag: --verbose.
  • Migrated the build system from GNU Make to CMake & Ninja. The preferred and recommended way to build the SystemC libraries and the SystemC modules moving forward is using CMake. Using GNU Make is still supported for backwards compatibility with existing configurations, however the build script for building the libraries now requires CMake and Ninja in PATH. The latest Simics Base package is also required.
  • The Transaction gasket now leaves transaction deferral disabled by default. Users can opt in by calling Transaction::set_deferrable(true). Because the benefit of deferral is model- and workload-dependent, this is an explicit integrator decision; see the “Asynchronous Completion” chapter in the Programming Guide for guidance.

7.22.0 (build 7131)

SystemC Library

  • Improved the transaction path by removing redundant DMI handling logic. The logic is already done for io_memory and transaction gaskets and should never be done for other gaskets.
  • Now the TransactionExtension is reset when a payload is returned to the TransactionPool, preventing stale state from leaking into subsequent transactions.
  • Disabled the DMI support for gasket when simics2tlm::ExtensionSender is used as DMI would bypass the extension dispatch logic.
  • Optimized the DMI path for io_memory and transaction gaskets. Checking for DMI earlier increased performance ~9% compared to the old implementation.
  • Improved robustness of composite::PcieGasket gasket to handle cases where device_id inputs of the connected and disconnect methods may contain non-zero function numbers.

7.21.0 (build 7125)

SystemC Library

  • The DMI attribute returned by get_direct_mem_ptr is now validated against the requested transaction’s address range and access type. If the DMI region does not fully cover the request or lacks the required access, a message is logged.

7.20.0 (build 7122)

SystemC Library

  • Added TransactionDataBufferPool, reuse of buffers to reduce allocation overhead.

7.19.0 (build 7118)

SystemC Library

  • Improved error handling of setting CCI attribute values. Now when trying to set an invalid attribute the error is always reported as a Simics attribute error. Previously it was sometimes reported during the end-of-elaboration phase.

7.18.0 (build 7115)

SystemC Library

  • Moved the c++-api code from src/devices to src/extensions. For SystemC modules using SYSTEMC = yes, this change has no impact. For other modules, if the path to c++-api is hardcoded, please update it to reflect the new location.

7.17.0 (build 7105)

SystemC Library

  • No memory or I/O mapping occurs when the PCIe gasket receives the pcie_device interface method connected and hotReset calls.

7.16.0 (build 7102)

SystemC Library

  • Corrected the calculation of the length for PCI/PCIe memory mapping when the size is greater than or equal to 32 bits.

7.15.0 (build 7101)

SystemC Library

  • Discontinued the handling of retrieveFunctionData when the PCI/PCIe SystemC model is unable to perform transport_dbg.

7.14.0 (build 7095)

SystemC Library

  • Added support for SIMICS_API 7 to the composite PCIe gasket.

7.13.0 (build 7088)

SystemC Library

  • Added support for configuring the SystemC time resolution through the Simics attribute sc_time_resolution (fixes SIMICS-23122).

7.12.0 (build 7087)

SystemC Library

  • Added simics2tlm serial_peripheral_interface_slave and tlm2simics serial_peripheral_interface_master gaskets. The new gaskets are used to connect a SystemC SPI slave device with a Simics SPI master device.
  • Added support for different SystemC simulation time resolutions.
  • Added support for configuring the frequency of the SystemC adapter. By setting the frequency attribute, users can control the amount of time that advances in SystemC for each Simics cycle.

7.11.0 (build 7079)

SystemC Library

  • Adjust SC verbosity level according to Simics log level (fixes SIMICS-23083).

7.10.0 (build 7075)

7.9.0 (build 7071)

SystemC Library

  • Replaced offending words/phrases with inclusive language (fixes SIMICS-23059).

7.8.0 (build 7069)

SystemC Library

  • Enhanced the logic for determining AS_VERSION and LD_VERSION. The updated logic now identifies version patterns in the format X.Y.

7.7.0 (build 7064)

SystemC Library

  • Removed unused simics::iface::PciBusInterface class.

7.6.0 (build 7063)

SystemC Kernel

  • Resolved MSVC 2022 warning C4530 by adding /EHsc flag.

7.5.0 (build 7061)

SystemC Checkpoint Documentation

  • Added back the PDF documentation (fixes SIMICS-22949).

7.4.0 (build 7055)

SystemC Library

  • Added optional '-std'/'--cxx-standard' option to the build-systemc-libraries build script to enable building libs with a different C++ language standard. Current supported options are 14 and 17.

7.3.0 (build 7053)

SystemC Library

  • A clear error message is now printed when SYSTEMC_KERNEL_VERSION is not set.
  • Added support for SystemC kernel version 3.0.0. Current build options for SYSTEMC_KERNEL_VERSION are 2.3.3, 2.3.4 and ‘3.0.0’.

7.2.0 (build 7046)

SystemC Kernel

  • Added kernel 2.3.4.1_20240904-Intel. Use build option SYSTEMC_KERNEL_VERSION to select the kernel version.

SystemC Library

  • Moved some GNU Make definitions from Base into SystemC add-on package. SystemC users using Simics Base 6.0.209 or newer must upgrade 1013 add-on package to version 7.2.0.
  • The SystemC libraries have been reorganized and are now located in separate subdirectories based on their respective kernel versions. Specifically, you can find them under: <host>/lib/systemc/2.3.3 and <host>/lib/systemc/2.3.4
  • Added '--version' option to the build-systemc-libraries build script to enable building libs with a different version of SystemC kernel. The default version used is 2.3.3.
  • Updated the version check logic. The SCL_VERSION variable now uses the build-id of package 1013 (SystemC-Library).
  • All variables ending in _not_set in the class PcieTlmExtension have been renamed to end with _set to improve clarity and consistency. They now default to false, indicating that the corresponding variable is not set.
  • Extended the class PcieTlmExtension with ide_secured ATOM support.
  • Added support for selecting SystemC kernel versions. Current build options for SYSTEMC_KERNEL_VERSION are 2.3.3 and 2.3.4. Users of add-on package #7213 must upgrade to the latest version.
  • The C++ language standard C++14 (-std=c++14) is no longer used by default. Now the default C++ language standard is determined by the compiler, i.e, C++17 for GCC 12.

7.1.0 (build 7039)

SystemC Library

  • Extended get_device_id method of tlm2simics::pcie_map class with parameter dev_obj. This makes it easier to support PCIe ports.
