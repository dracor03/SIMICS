GUI Installation Guide

This application has a dependency on Python* and must be available on your host machine. On Linux that usually entails making sure python3 is in your PATH.

If you are using Windows you may first need to install python or the dedicated Intel Simics package with python (package 1033 Simics Python), and then give the application its location in the Settings options in the host context menu.

1 Software And Hardware Requirements

The GUI is built on top of Node.js*, Electron*, and Chromium*, and its host requirements are based on the requirements of those frameworks. It has been tested to work on:

  • 64-bit Windows 11 (and equivalent server versions of Windows)
  • 64-bit recent Linux versions. It has been tested on Fedora* 39 and later.

2 Install GUI

As a customer you should have received instructions that describes which package to install and where to find it. If this is not the case, contact your provider to obtain this information.

For the installation, use the Intel® Simics® Package Manager. The package manager can be used to check for updated packages, download and install/uninstall, and manage Intel Simics projects, also called "user projects". It supports both command line (batch) mode and GUI mode.

The simulator is delivered in packages, each one containing different parts of the functionality. There is a Simics Base package and several add-on packages. The GUI is provided in one of those add-on packages (package 1015 Simics GUI).

The package manager can create user projects with Simics Base and other add-on packages. A user project is a directory for adding user files and developing simulation models, and is typically set up for a combination of a few packages of certain versions. Thus such projects enable users to work with different package combinations just by switching between projects.
