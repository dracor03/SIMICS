qsp-x86-v2/yocto-linux

About the Target

The yocto-linux target is a target that boots the Yocto Linux image defined in the parameter software:os_image. Please check the documentation of this parameter to see which Yocto image is recommended. On top of this the image defined in software:os_configuration_diff_image will be applied as a diff. The default image is a prebuilt image from the Yocto project and the default diff image adds the Simics Agent and makes the image more useful to Simics users. The recommendation is to use the default values for the os_image and the diff image.

        Class from which remap units are instantiated. That means, when changing this parameter, the end user or the target script must create all remap unit connectivity.
        • Type: str

          • Type: bool

For example, ‘[[2,4],[6,2]]’ will define two ports, one with ID=2 and width=4, while the other has ID=6 and width=2.
