2 QSP-x86-v2 Overview

The QSP-x86-v2 is a made up system that does not exist in real hardware. QSP stands for Quick-Start Platform. The purpose of QSP-x86-v2 is to have an easy system for application development, architectural studies, demos, etc.

The QSP-x86-v2 system comes with device models and a UEFI BIOS. The system allows a generic PC operating system to be installed provided it is compatible with a UEFI BIOS and respects the ACPI tables provided by the BIOS. Note that version 2 of the QSP-x86 has been radically minimized with only modern operating systems in mind. Legacy devices like port I/O based DMA, PS/2 keyboards and mouse, legacy PIC, floppy disks and more have been removed. The QSP-x86-v2 does not support virtual wire IRQ mode. PCI(e) devices are expected to use MSI.

The QSP-x86-v2 package does not contain the processor core which is used by default in the included simulated machines. You need the package QSP-CPU, which contains the default processor core as well as various recent processor cores.
