qsp-x86/clear-linux

  • machine
    • system_info
      A short string describing what this system is.
      • Type: str
      • Default value: Clear Linux with UEFI
    • hardware:name
      Name of the machine. Used for the top-level component.
      • Type: str
      • Default value: qsp
      • Required: True
    • hardware:memory_megs
      Amount of RAM in the machine, in MiB. The highest supported value is 65536 (64 GiB).
      • Type: int
      • Default value: 8192
    • hardware:processor:class
      It should be specified as processor component class without the “processor_” prefix and with underscores replaced with hyphens, e.g. x86-skylake. Tip: to obtain the list of processor component classes please use the “list-classes substr = processor_” Simics command.
      • Type: str
      • Default value: x86QSP3
    • hardware:processor:num_cores
      Number of cores per physical processor or slot in the machine. Allowed values are 1 - 128.
      • Type: int
      • Default value: 1
    • hardware:processor:freq_mhz
      Processor frequency in MHz.
      • Type: int
      • Default value: 2000
    • hardware:processor:cpi
      Clock cycles per executed instruction for the processors. Must be a power of 2.
      • Type: int
      • Default value: 1
    • hardware:processor:num_slots
      Number of physical processors (sockets/packages) in the machine.
      • Type: int
      • Default value: 1
    • hardware:processor:num_dies
      Number of dies per package (if package supports dies).
      • Type: int
      • Default value: 1
    • hardware:processor:num_modules
      Number of modules per die (if modules are supported).
      • Type: int
      • Default value: 1
    • hardware:processor:num_cores_small
      Number of small cores per physical processor in the machine (only applicable if the processor class specified by the cpu_comp_class parameter supports heterogeneous setups).
      • Type: int
      • Default value: 0
    • hardware:processor:num_threads
      Number of threads per processor core in the machine.
      • Type: int
      • Default value: 1
      • Allowed values: [1, 2, 4]
    • hardware:processor:num_threads_small
      Number of threads per small core in the machine (only applicable if the processor class specified by the cpu_comp_class parameter supports heterogeneous setups).
      • Type: int
      • Default value: 0
      • Allowed values: [0, 1, 2, 4]
    • hardware:processor:apic_freq_mhz
      APIC frequency in MHz.
      • Type: int
      • Default value: 133
    • hardware:processor:do_not_initialize_mtrr
      If true, prevents the motherboard component from initializing the mtrr registers of the cores. Can stay turned off when using the UEFI BIOS.
      • Type: bool
      • Default value: True
    • hardware:consoles:con0:create
      Create a console for COM1 (a.k.a. com[0]).
      • Type: bool
      • Default value: True
    • hardware:consoles:con0:show
      Automatically display the text console on the first serial port.
      • Type: bool
      • Default value: True
    • hardware:consoles:con0:fg_color
      The foreground color, or RGB in #12ab89 format.
      • Type: str
      • Default value: #80ff80
    • hardware:consoles:con0:bg_color
      The background color, or RGB in #12ab89 format.
      • Type: str
      • Default value: black
    • hardware:consoles:con1:create
      Create a console for COM2 (a.k.a. com[1]).
      • Type: bool
      • Default value: False
    • hardware:consoles:con1:show
      Automatically display the text console on the second serial port.
      • Type: bool
      • Default value: False
    • hardware:consoles:con1:fg_color
      The foreground color, or RGB in #12ab89 format.
      • Type: str
      • Default value: white
    • hardware:consoles:con1:bg_color
      The background color, or RGB in #12ab89 format.
      • Type: str
      • Default value: black
    • hardware:consoles:gfx_con:create
      Create a graphics console.
      • Type: bool
      • Default value: True
    • hardware:consoles:gfx_con:show
      Automatically display the graphics console.
      • Type: bool
      • Default value: True
    • hardware:consoles:gfx_con:no_gpu_if_no_console
      Do not create a GPU if no graphics console is created.
      • Type: bool
      • Default value: False
    • hardware:storage:disk0:name
      The name of the disk component.
      • Type: str
    • hardware:storage:disk0:slot
      IDE/SATA/PCIe slot to connect to.
      • Type: str
    • hardware:storage:disk0:create
      • Type: bool
      • Default value: True
    • hardware:storage:disk0:interface
      Create and connect to the target machine a virtual hard disk of type SATA, IDE, or NVMe. Simics object machine_name.disk0 is created and connected to the target machine.
      • Type: str
      • Default value: sata
      • Allowed values: [‘sata’, ‘ide’, ‘nvme’]
    • hardware:storage:disk0:image
      Disk image file for the machine_name.disk0 virtual disk. Files in craff (Simics own file format), VHDX, and raw formats are supported.
      • Type: file
      • Default value: ^software:linux:os_image
    • hardware:storage:disk0:size
      Size of the machine_name.disk0 virtual disk in bytes. If NIL, the size of disk0_image is used.
      • Type: int
    • hardware:storage:disk1:name
      The name of the disk component.
      • Type: str
    • hardware:storage:disk1:slot
      IDE/SATA/PCIe slot to connect to.
      • Type: str
    • hardware:storage:disk1:create
      • Type: bool
      • Default value: True
    • hardware:storage:disk1:interface
      Create and connect to the target machine a virtual hard disk of type SATA, IDE, or NVMe. Simics object machine_name.disk0 is created and connected to the target machine.
      • Type: str
      • Default value: sata
      • Allowed values: [‘sata’, ‘ide’, ‘nvme’]
    • hardware:storage:disk1:image
      Disk image file for the machine_name.disk0 virtual disk. Files in craff (Simics own file format), VHDX, and raw formats are supported.
      • Type: file
      • Default value: ^software:linux:auxiliary_image
    • hardware:storage:disk1:size
      Size of the machine_name.disk0 virtual disk in bytes. If NIL, the size of disk0_image is used.
      • Type: int
    • hardware:storage:cdrom:create
      • Type: bool
      • Default value: True
    • hardware:storage:cdrom:name
      The name of the cdrom component.
      • Type: str
      • Default value: cdrom
    • hardware:storage:cdrom:interface
      Create and connect to the target machine a virtual hard disk of type SATA or IDE. Creates a Simics object called machine_name.disk0, connected to the target machine.
      • Type: str
      • Default value: sata
      • Allowed values: [‘sata’, ‘ide’]
    • hardware:rtc:time
      The date and time of the simulated real-time clock set when the configuration is created. The format is “YYYY-MM-DD HH:MM:SS”. Can also be set to “auto” to use the current host time.
      • Type: str
      • Default value: auto
    • hardware:usb_tablet:create
      Connects a USB tablet device for input using absolute positioning that provides a better user experience than a mouse.
      • Type: bool
      • Default value: True
    • hardware:apic_bus:class
      APIC bus class. It should be the apic bus class that comes with the same module as the apic used in the CPU model. If set to “auto_apic_bus” the script will attempt to find the correct apic bus class automatically. If that fails the apic-bus class will be used.
      • Type: str
      • Default value: apic_bus_v2
    • hardware:external_remap_unit:class
      Setting this to a classname will create two instances of this class and set the external_remap_unit connect of the X58 core device function 0 to point to these two instances.
      • Type: str
      • Default value: NIL
    • hardware:root_ports:class
      Setting this to a classname will override the default root port class used in the root ports of the X58 core device.
      • Type: str
      • Default value: x58-pcie-port
    • hardware:nic:mac_address
      MAC address of the built-in Ethernet adapter in the ICH10 chipset. The format is “XX:XX:XX:XX:XX:XX”. Can also be set to “auto” to obtain an auto-generated unique MAC address.
      • Type: str
      • Default value: auto
    • hardware:smbus_ctrl:use_i2c_v2
      Use i2c v1 or v2 for the SMBUS.
      • Type: bool
      • Default value: False
    • hardware:pcie_demo_led_device:enabled
      Set to true to add PCIe demo card
      • Type: bool
      • Default value: False
    • hardware:pcie_demo_led_device:master_system
      The name of the system inside of which we create the card
      • Type: str
    • hardware:pcie_demo_led_device:subsystem_name
      Name of the PCIe demo device
      • Type: str
      • Default value: demo_card
    • hardware:pcie_demo_led_device:pcie_slot
      The PCIe slot to which to connect the card
      • Type: str
    • hardware:pcie_demo_led_device:device_type
      • Type: str
      • Allowed values: [‘systemc’, ‘dml’]
    • hardware:pcie_demo_led_device:serconsole
      The serial console used to upload driver and command
      • Type: str
    • hardware:firmware:bios
      BIOS file.
      • Type: file
      • Default value: ^software:firmware:bios
    • hardware:firmware:lan_bios
      ROM BIOS file for the ICH10 LAN Ethernet adaptor
      • Type: file
    • hardware:firmware:spi_flash
      The ICH10 SPI flash file to use.
      • Type: file
      • Default value: ^software:firmware:spi_flash
    • hardware:simulation:enable_break_on_reboot
      Interrupts the simulation if the machine is rebooted.
      • Type: bool
      • Default value: ^simulation:enable_break_on_reboot
    • hardware:simulation:system_clock:enable
      Enables a configuration with a separate clock to which devices are bound instead of to the first CPU.
      • Type: bool
      • Default value: ^simulation:system_clock:enable
    • hardware:simulation:system_clock:class
      The class used for the system clock if the enable_system_clock parameter is true.
      • Type: str
      • Default value: ^simulation:system_clock:class
    • hardware:simulation:use_vmp
      Enables host virtualization (VMP) for better simulation performance. This option affects simulated time. See the performance chapter in the Simics User’s Guide for more information about VMP.
      • Type: bool
      • Default value: ^simulation:use_vmp
    • hardware:simulation:uefi_dev_name
      Name of Simics UEFI device. Will not be instantiated if set to empty string (the default).
      • Type: str
      • Default value:
    • hardware:output:system
      The system top-level component object, output parameter
      • Type: str
    • hardware:output:console
      The serial console of the created system, output parameter
      • Type: str
    • hardware:output:mac_address
      The mac address assigned to the NIC, output parameter
      • Type: str
    • hardware:output:eth_slot
      Board ethernet connector, output parameter
      • Type: str
    • software:firmware:bios
      BIOS file.
      • Type: file
      • Default value: %simics%/targets/qsp-x86/images/SIMICSX58X64_2_0_0_r.fd
    • software:firmware:lan_bios
      ROM BIOS file for the ICH10 LAN Ethernet adaptor
      • Type: file
    • software:firmware:spi_flash
      The ICH10 SPI flash file to use.
      • Type: file
      • Default value: %simics%/targets/qsp-x86/images/spi-flash.bin
    • software:linux:os_image
      Bootable disk image that will be used for the first disk and should auto-boot the desired OS.
      • Type: file
      • Default value: %simics%/targets/qsp-x86/images/cl-b28910-v2.craff
    • software:linux:auxiliary_image
      Optional image that will be used for the second disk.
      • Type: file
      • Default value: %simics%/targets/common/images/efi_agent_and_grub_only.craff
    • software:linux:auto_login
      Automatically log in as a “simics” user on the serial console.
      • Type: bool
      • Default value: True
    • software:linux:auto_login_root
      Automatically log in as a “root” user on the serial console. When the parameter is set it overrides the “auto_login” parameter.
      • Type: bool
      • Default value: False
    • software:osa:create
      Create the top-level node for OS awareness. Does not configure the OS awareness.
      • Type: bool
      • Default value: True
    • software:osa:create_tracker
      Creates the Linux tracker object.
      • Type: bool
      • Default value: True
    • software:osa:tracker_params
      OS awareness parameter file for the Linux kernel running on the machine.
      • Type: file
      • Default value: %simics%/targets/qsp-x86/images/cl-b28910-v2.params
    • simulation:use_vmp
      Enables host virtualization (VMP) for better simulation performance. This option affects simulated time. See the performance chapter in the Simics User’s Guide for more information about VMP.
      • Type: bool
      • Default value: True
    • simulation:enable_real_time_mode
      Enables real-time mode after having logged in to Linux. See command ‘enable-real-time-mode’.
      • Type: bool
      • Default value: False
    • simulation:enable_break_on_reboot
      Interrupts the simulation if the machine is rebooted.
      • Type: bool
      • Default value: False
    • simulation:system_clock:enable
      Enables a configuration with a separate clock to which devices are bound instead of to the first CPU.
      • Type: bool
      • Default value: False
    • simulation:system_clock:class
      The class used for the system clock if the enable_system_clock parameter is true.
      • Type: str
      • Default value: clock
  • network
    • switch:create_network
      Creates an Ethernet switch and connects the primary Ethernet adapter to it.
      • Type: bool
      • Default value: True
    • switch:ethernet_switch:name
      Name of the created ethernet switch
      • Type: str
      • Default value: ethernet_switch
    • switch:ethernet_switch:global_id
      Global ID for the link in a distributed setup (it should only be set if the link should be distributed and must match the links in other Simics sessions).
      • Type: int
      • Default value: 0
    • switch:ethernet_switch:goal_latency
      Goal latency in seconds for communication (see also the set-min-latency command)
      • Type: float
      • Default value: 1e-05
    • service_node:create
      Create a service node.
      • Type: bool
      • Default value: True
    • service_node:name
      Name of the created service node
      • Type: str
      • Default value: service_node
    • service_node:ethernet_switch
      • Type: str
      • Default value: ^network:switch:ethernet_switch:name
      • Required: True
    • service_node:ip_address
      IP address of the service node
      • Type: str
      • Default value: 10.10.0.1
    • service_node:clock
      Name of clock to use for service node
      • Type: str
    • service_node:connect_real_network
      Connects the simulated Ethernet switch to the host network using NAPT (Network Address and Port Translation)
      • Type: str
      • Allowed values: [‘napt’]
    • service_node:dhcp:setup
      Setup service node DHCP service
      • Type: bool
      • Default value: True
    • service_node:dhcp:domain
      Domain name to use for the DHCP server in the service node
      • Type: str
      • Default value: network.sim
    • service_node:dhcp:pool:starting_ip_address
      First IP address to serve from the DHCP server in the service node
      • Type: str
      • Default value: 10.10.0.100
    • service_node:dhcp:pool:size
      Size of the IP address pool for the DHCP server in the service node
      • Type: int
      • Default value: 100
    • ip_address
      The IP address to assign to the given MAC over DHCP
      • Type: str
      • Default value: auto
  • persistent_state

      The root of the hierarchy for the persistent state objects.
      • Type: str

    • writable_state_dir
      If not NIL, the parameter is interpreted as a directory name. It is passed as an argument to the enable-writable-persistent-state command in order to set up a writable persistent state for the configuration.
      • Type: str
  • output

      • Type: str

      • Type: str
