6 Processor-specific Features and Limitations

Not all types of cache modeling features are supported by all processor types. The instrumentation API needs to be supported in order to do cache modeling for a specific processor.

Currently ARC, ARM, MIPS, PPC, X86 and Xtensa target architectures support instrumentation.
