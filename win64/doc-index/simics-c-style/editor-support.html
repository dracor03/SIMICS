9 Editor support

The following will help following these rules when using Emacs. Place in your .emacs file:

(setq load-path (cons "/home/packages/vt-elisp" load-path))
(load "vt-elisp-start")

This does not absolve you from doing the right thing where Emacs is wrong (which, unlikely as it sounds, may happen occasionally).

For more information, read /home/packages/vt-elisp/README.
